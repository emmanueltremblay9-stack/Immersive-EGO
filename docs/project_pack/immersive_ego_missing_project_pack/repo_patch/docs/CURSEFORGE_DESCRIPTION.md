# Immersive EGO 🧬🌡️💧

**Immersive EGO** is a configurable survival-RPG simulation mod for Minecraft **1.21.1 NeoForge**.

Instead of adding piles of new blocks or items, Immersive EGO turns the player into a connected survival system: climate, hydration, respiration, stamina, fatigue, sleep, food variety, gut health, stress, pain, biome origin, acclimation, recovery, and readiness all influence each other.

## Core features ⚙️

- 🧬 Server-authoritative EGO state
- 💧 Hydration and water-quality rules
- 🌡️ Original heat/cold thermoregulation
- 🫁 Contextual respiration from altitude, depth, dimension, load, and exertion
- 🏃 Stamina, fatigue, and encumbrance
- 😴 Deep sleep pressure, sleep quality, naps, and recovery budget
- 🍲 Nutrition groups, dietary memory, meal quality, and gut health
- 🧠 Gameplay stress, fear, stability, focus, and comfort
- 🏜️ Biome origins and acclimation axes
- 📊 Apothic Attributes stat display
- 🛠️ Config-first balancing for modpacks

## Design rules 🧱

Immersive EGO does **not** add new blocks, items, entities, fluids, machines, or Blockbench models in the initial design. Existing vanilla and modded content drives progression.

## Dependencies 📦

Required:

- Apothic Attributes
- MariesLib

Optional:

- Apotheosis
