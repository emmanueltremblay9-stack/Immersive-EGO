# Asset Policy

## Allowed

- Original Immersive EGO assets created for this repository.
- Text-only documentation and translations created for this repository.
- Generated icons/banners whose sources are saved under `branding/`.
- Public-domain or permissively licensed assets only after recording provenance.

## Forbidden

- Apothic Attributes textures, icons, GUI atlas, sounds, language files, logos, or screenshots copied into this repository.
- Apotheosis textures, icons, GUI atlas, sounds, language files, logos, or screenshots copied into this repository.
- Cold Sweat assets or copied UI concepts.
- Assets from All Rights Reserved mods.
- AI-generated assets trained/derived from a specific mod's protected artwork style or logo.

## Branding direction

Use an original identity:

- Bio-organic circuitry
- Compass/biome motif
- Subtle survival-stat glyphs
- No borrowed gear textures or Apothic/Apotheosis visual language

## File policy

Store source vector assets where practical. Export PNGs only from owned SVG/vector sources.
