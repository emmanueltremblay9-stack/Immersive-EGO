# Modpack Guide

## Required mods

- Immersive EGO
- Apothic Attributes
- MariesLib
- Placebo if not already pulled transitively by Apothic Attributes

## Optional

- Apotheosis

## Pack configuration

Use server configs for authoritative gameplay. Do not use client configs to rebalance survival mechanics.

## Presets

- CASUAL: lower penalties, no critical damage by default.
- IMMERSIVE: intended baseline.
- HARDCORE: stronger consequences and lower safety margins.
- CUSTOM: pack-controlled.

## Datapack/config extension points

- food overrides
- item weights
- climate profiles
- origin profiles
- dimension profiles
- synergy edges

## Compatibility warning

Do not include Cold Sweat as an integration target for Immersive EGO. This project intentionally implements its own thermoregulation model.
